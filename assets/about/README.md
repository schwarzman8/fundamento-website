# O nama slike

Uploadaj slike u ovu mapu i nazovi ih ovako:

- `about-main.jpg` - glavna slika kraj teksta
- `about-mosaic-01-wide.jpg` - prva široka slika u mozaiku
- `about-mosaic-02-tall.jpg` - prva vertikalna slika u mozaiku
- `about-mosaic-03-square.jpg` - kvadratna slika u mozaiku
- `about-mosaic-04-tall.jpg` - druga vertikalna slika u mozaiku
- `about-mosaic-05-wide.jpg` - druga široka slika u mozaiku
- `about-mosaic-06-square.jpg` - zadnja kvadratna slika u mozaiku
- `about-mosaic-07-tall.jpg` - desna vertikalna slika koja popunjava prazninu u mozaiku

Stranica trenutno koristi optimizirane `.jpg` verzije ovih slika. Originalne `.jpeg` datoteke mogu ostati u mapi kao backup.

Ako kasnije uploadas nove slike kao `.png`, `.jpeg` ili `.webp`, samo mi javi ekstenzije pa cu ih optimizirati i povezati u `about.html`.
